# Distance Calculator: How to Use
## Description
This README helps the user to understand the use of this Distance Calculator.

## How to run the program
To run the program, you must first open the program in Google Colab, then click the start button to start.

## Inputs Needed
For the inputs, you only need to input numbers (float). For example,
- x1 = 6
- y1 = 7
- x2 = 4
- y2 = 1
