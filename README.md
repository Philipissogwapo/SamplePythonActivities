# Distance Calculator: How to Use
## Description
This README helps the user to understand the use of this Distance Calculator. The calculator helps the user calculate the distance between two points.

## How to Run the Program
To run the program, you must first open the program in Google Colab, then click the start button to start. After, plug in the values you want and check the result.

## Inputs Needed
For the inputs, you only need to input numbers (float). For example,
- x1 = 6
- y1 = 7
- x2 = 4
- y2 = 1

## Sample Output
If you use the inputs from the inputs needed, the calculator will output this:

**The distance between the two points is 6.32**
